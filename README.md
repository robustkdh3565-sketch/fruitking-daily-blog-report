# 프룻킹 데일리 블로그 리포트

매일 자동 실행은 [DAILY_RUN_COMPACT.md](DAILY_RUN_COMPACT.md)를 우선 읽습니다. 전체 규칙 문서는 검증 실패나 기준 충돌이 발생한 경우에만 해당 항목을 선택적으로 확인합니다.

> 최상위 작성 기준은 [`ABSOLUTE_RULES.md`](ABSOLUTE_RULES.md)이며 다른 규칙과 충돌할 경우 이 문서를 우선합니다.

매일 발행되는 `커뮤니티 리서치`와 `건강주제 리서치`에서 프룻킹과 자연스럽게 연결할 수 있는 소재를 선정해 블로그 초안으로 정리합니다.

## 리포트 구성

1. 오늘의 최종 선정 주제
2. 커뮤니티 화제와 주요 내용
3. 방송 프로그램과 주요 내용
4. 프룻킹 연결 근거
5. 추천 제목
6. 간략 공유문
7. 상세 블로그 초안
8. 원문 및 제품 구매 URL

연결 가능한 주제가 없는 날에는 억지로 제품을 붙이지 않고 `적합 주제 없음`으로 기록합니다.

글자 수, 이미지, 영상, 제목, 키워드, 톤과 무드는 [`NAVER_BLOG_WRITING_RULES.md`](NAVER_BLOG_WRITING_RULES.md)를 적용합니다. 고정된 형식을 반복하지 않고 매일 대표 키워드의 네이버 블로그 관련도순 상위 10개를 분석해 목표값을 정합니다.

제품 구매 링크는 [`PURCHASE_LINKS.md`](PURCHASE_LINKS.md)에 지정된 스마트스토어 URL 두 개만 사용합니다.
